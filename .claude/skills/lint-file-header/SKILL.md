---
name: lint-file-header
description: Checks for the presence of a file header with appropriate description
---

Every Go file that is NOT generated or has `managed: true` in the file header should have:
1. Copyright notice `// Copyright 2026 Outreach Corporation. All Rights Reserved.`
2. a file header that includes a description `Description:` of the file's purpose and functionality.
3. In case of package info file, it should also include a package-level comment describing the purpose of the package.

What to do
- Use standard tools like grep to find files that are missing documentation
- Find files that are missing the file header and add the appropriate file header with description.
- Find packages with missing package-level comments and add appropriate package-level comments describing the purpose of the package.

What to not do
- In case of there is a copyright notice with old year, DO NOT update it.

## Example of the file header (stringutil/random.go)

```go
// Copyright 2024 Outreach Corporation. All Rights Reserved.

// Description: This file contains utility functions for random number generation

package stringutils
```

## Example of a package info file (stringutil/stringutil.go)

```go
// Copyright 2024 Outreach Corporation. All Rights Reserved.

// Description: This file contains package level documentation and code for the stringutils package.

// Package stringutils provides utility functions for string manipulation
package stringutils
```

## Example of a generated file that should be ignored (stringutil/stringutil_gen.go)

```go
// Code generated by stringutil_gen.go DO NOT EDIT.
// This file was generated by the stringutil
```
